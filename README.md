# test-agent

Тестовый репозиторий для проверки супер-агента.

## О проекте

Это тестовый репозиторий, предназначенный для проверки работы супер-агента. Он не содержит реального проекта и используется как песочница для экспериментов.

## Как запустить

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/ivan-agent-wq/agent-playground.git
   ```

2. Перейдите в каталог проекта и откройте `README.md` — исполняемого кода в репозитории нет, поэтому дополнительный запуск не требуется.
